# Project Demonstration

This directory contains the project demonstration webpage and its video.

## Files

- `index.html`: the project demonstration webpage.
- `demo.mp4`: the demonstration video displayed on the webpage.
- `README.md`: this explanatory file, also available from the webpage through the **Download README** link.

## Preview locally

Keep the three files in the same directory, then open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a GitHub repository for the website.
2. Extract this package and upload `index.html`, `demo.mp4`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. After deployment completes, open the URL shown in the Pages settings.

The webpage uses relative file paths (`demo.mp4` and `README.md`), so keep these files together in the repository root. The video is approximately 50.6 MB; it is below GitHub's 100 MB per-file limit.
